## Selected projects

### [AI Pharmacy Manager](https://github.com/alvinsakhiya/Ai-Pharmacy-Manager)

A full-stack pharmacy operations platform built with React, TypeScript, Django REST Framework and PostgreSQL.

The system brings together:

* stock and batch management
* FEFO expiry review
* dosette and MDS workflows
* operational reports
* audit logging
* role-based access
* backup and restore
* explainable stock forecasting and transfer suggestions

The project uses fictional demonstration data and is designed as an operational prototype, not a clinical system.

### [EdgeGuard](https://github.com/alvinsakhiya/edgeguard-tinyml)

An on-device TinyML prototype for detecting fall-like events using an Arduino Nano 33 BLE Sense Rev2.

It combines accelerometer and gyroscope data with Edge Impulse inference, hybrid motion checks, inactivity verification, a cancellable alert countdown, BLE status updates and a Streamlit monitoring dashboard.

The final binary model achieved 93.41% model-testing accuracy. The project is an engineering prototype and is not presented as a medical device.

### [PharmaMedia](https://github.com/alvinsakhiya/pharmamedia)

A cloud-hosted multimedia asset management platform built around Microsoft Azure services.

It includes media uploads, metadata management, search, filtering, CRUD workflows, responsive previews and automated deployment.

The project uses:

* Azure App Service
* Azure Blob Storage
* Azure Cosmos DB
* Azure Logic Apps
* Application Insights
* GitHub Actions
