A privacy-first TinyML fall-like event detection engineering prototype running locally on an Arduino Nano 33 BLE Sense Rev2.

It combines IMU sensing, Edge Impulse, quantised inference, hybrid verification, cancellable local alerts, BLE communication and a Streamlit monitoring dashboard.

A Microsoft Azure cloud-native multimedia asset management platform using App Service, Blob Storage, Cosmos DB, Logic Apps, Application Insights and GitHub Actions.
