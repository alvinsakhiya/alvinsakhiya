About me

I am a London-based junior software developer and BSc (Hons) Computing Systems graduate building practical, secure systems across full-stack web development, cloud platforms and embedded machine learning.

Alongside software development, I work in community pharmacy as a Pharmacy Dispenser and Vaccinator. That experience gives me first-hand understanding of accuracy-critical workflows, patient confidentiality, stock and expiry control, and the importance of software that remains clear and dependable under real operational pressure.

I am especially interested in:

full-stack applications with well-structured APIs and data models;

healthcare and pharmacy operations technology;

cloud-native systems and automated delivery pipelines;

privacy-first edge AI and TinyML.

Selected projects

AI Pharmacy Manager

<a href="https://github.com/alvinsakhiya/Ai-Pharmacy-Manager">
  <img src="./assets/ai-pharmacy-manager-card.svg" width="100%" alt="AI Pharmacy Manager project card" />
</a>

A secure, role-based pharmacy operations platform bringing stock control, batch and FEFO expiry management, dosette/MDS workflows, reports, audit logging, guarded backup and restore, and explainable stock intelligence into one system.

Built with: React, TypeScript, Vite, Tailwind CSS, Django REST Framework, PostgreSQL, Docker, pytest, Vitest and Playwright.

Uses fictional demonstration data and provides operational decision support only; it does not make clinical decisions or integrate with NHS systems.

EdgeGuard

<a href="https://github.com/alvinsakhiya/edgeguard-tinyml">
  <img src="./assets/edgeguard-card.svg" width="100%" alt="EdgeGuard project card" />
</a>

A privacy-first, on-device TinyML fall-like event detection engineering prototype for the Arduino Nano 33 BLE Sense Rev2. It combines six-axis IMU sensing, quantised inference, hybrid motion verification, inactivity checks, a cancellable alert workflow, BLE observability and a Streamlit dashboard.

Selected result: the final M4 int8 model achieved 93.41% official model-testing accuracy; the dashboard validation suite contains 352 automated tests.

Engineering prototype only — not a medical device or clinically validated emergency system.

PharmaMedia

<a href="https://github.com/alvinsakhiya/pharmamedia">
  <img src="./assets/pharmamedia-card.svg" width="100%" alt="PharmaMedia project card" />
</a>

A cloud-native multimedia asset platform for organising pharmacy-related images, SOPs, training media and packaging assets. It demonstrates managed Azure services, RESTful CRUD workflows, responsive UI design, monitoring and automated deployment.

Built with: Azure App Service, Blob Storage, Cosmos DB, Logic Apps, Application Insights, GitHub Actions, JavaScript and Bootstrap.
